# Pandas E-Commerce Project

##  Project Description
This project explores e-commerce transaction data using Python and Pandas. It focuses on understanding the dataset, exploring DataFrames, filtering data, transforming columns, and managing data quality.

##  Project Objectives
- Understand the dataset structure.
- Explore rows, columns, and data types.
- Select and filter records.
- Transform and manage data.
- Identify duplicate records and missing values.
- Generate CSV reports to summarize the dataset and data quality.

##  Tools and Technologies
- Python
- Pandas
- Google Colab / Jupyter Notebook
- GitHub

## ▶️ How to Run the Project
1. Download or clone this repository.
2. Install the required library:

   ```bash
   pip install -r requirements.txt
   ```

3. Open `onlineretail.ipynb` in Google Colab or Jupyter Notebook.
4. Ensure the dataset is available at the path used in the notebook.
5. Run the notebook cells in order.
